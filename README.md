\# SupplyTrack



SupplyTrack is a supply chain demand forecasting and inventory management system.

Live Application

https://supplytrack-controltower.streamlit.app/

Demo Video

https://drive.google.com/file/d/1NRfxVjC6IqKGDKfAIKNOGugGFgpmXi3M/view?usp=sharing

\## Features



\- Demand forecasting using XGBoost

\- Actual vs predicted demand analysis

\- Inventory risk monitoring

\- Warehouse-level demand and inventory analysis

\- Regional demand analysis

\- Replenishment recommendations

\- Forecast model evaluation

\- Interactive Streamlit dashboard



\## Tech Stack



\- Python

\- Pandas

\- Scikit-learn

\- XGBoost

\- Plotly

\- Streamlit

\- Joblib
